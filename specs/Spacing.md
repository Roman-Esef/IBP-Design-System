## Назначение
Модуль 4 px и колоночная сетка. Все отступы, зазоры и размеры кратны 4 px; горизонтальную структуру задают 12 резиновых колонок контентной области с постоянным зазором 16 px. Значения берутся из токенов `--space-*` / `--grid-*`.

## Ключевые правила (из разделов страницы)
- **Использование** — колоночная сетка = горизонтальная структура (ширина блока в колонках), шкала отступов = расстояния внутри и между блоками; вертикаль сетка не задаёт. Нарушения: значения вне шкалы (13/18/22/30), ширина колонки в px, контент в зазоре.
- **Модуль 4 px** — база 4 px, основной шаг ритма 8 px. Полушаги 2/6/10/14 — исключения только для микро-оптики (фокус-обводка, XS-контролы, круглые формы); новых не вводить.
- **Колоночная сетка** — 12 колонок, зазор 16 px постоянный, колонки резиновые (`minmax(0,1fr)`), поля внутри области по умолчанию 0 (задаёт лайаут экрана). Формула: `col = (W − 2·margin − (N−1)·gutter) / N`; дробная ширина колонки — норма. Типовые раскладки: 12 · 8+4 · 6+6 · 4+4+4 · 3+3+3+3. Вложенная сетка наследует зазор.
- **Где применяется** — таблица соответствий «расстояние → алиас → примитив».
- **Правила** — только из шкалы; близость = связь (внутри группы меньше, чем между группами); отступ задаёт контейнер через `gap`; чем крупнее блок, тем больше воздух; не складывать margin поверх padding.
- **Для разработчиков** — redline токенов (читается с `:root` через getComputedStyle) + псевдокод расчёта сетки и правило округления `v = round(v/4)*4`.
- **Бэклог** — адаптивные брейкпоинты (число колонок пока фиксировано 12), baseline-ритм, плотности, утилиты `.stack-*`/`.inline-*`, аудит компонентов на соответствие шкале.

## Токены

**Модуль**: `--space-unit` (4px)

**Шкала (кратно 4)**: `--space-0` `--space-4` `--space-8` `--space-12` `--space-16` `--space-20` `--space-24` `--space-32` `--space-40` `--space-48` `--space-64` `--space-80` `--space-96`

**Полушаги (исключения)**: `--space-2` `--space-6` `--space-10` `--space-14`

**Семантические алиасы**: `--gap-icon-text` (8) `--gap-label-field` (4) `--gap-inline` (8) `--gap-stack` (16) `--gap-group` (24) `--gap-section` (40) `--pad-control-s` (8) `--pad-control` (12) `--pad-card` (16) `--pad-panel` (24) `--pad-page` (32)

**Сетка**: `--grid-columns` (12) `--grid-gutter` (16px) `--grid-margin` (0)

## Разметка · утилиты

```html
<div class="grid12">
  <section class="col-8">контент</section>
  <aside class="col-4">панель</aside>
</div>
```

| Класс | Назначение |
|---|---|
| `.grid12` | CSS Grid на `--grid-columns` колонок с зазором `--grid-gutter` и полями `--grid-margin` |
| `style="--grid-gutter:var(--space-16)"` | локальная подмена зазора (инлайн на контейнере) |
| `.col-1` … `.col-12` | ширина блока в колонках (`grid-column: span N`) |
