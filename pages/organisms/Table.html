Table

Контейнер таблицы/реестра: Toolbar (заголовок, счётчик, фильтр, действия) + прокручиваемое тело с липкой шапкой + Footer. Строки и ячейки собираются из TableCell, постраничный переход и панель массовых действий — из Pagination; Table добавляет только обёртку, скролл-поведение и состояния Loading/Empty всей таблицы.

Конструктор

Таблица интерактивна: тяните правую границу колонки, чтобы изменить ширину, перетаскивайте подпись колонки, чтобы поменять порядок, отмечайте чекбоксы строк — тело прокручивается по вертикали и горизонтали, шапка остаётся на месте.

Использование

Table — верхнеуровневый контейнер для любого реестра: список сделок, заявок, документов, платежей. Он не рисует содержимое строк сам — колонки и ячейки собираются из TableCell, постраничная навигация и массовые действия — из Pagination.

Когда использовать

Любой список записей с колонками, который может не поместиться на экран целиком: нужен скролл, липкая шапка, счётчик, фильтр или массовые действия над выбранными строками.

Когда не использовать

Короткий фиксированный список из 2–4 полей без прокрутки и без операций над строками — проще собрать на Entity или ReadOnlyField, без веса контейнера Table.

Table vs TableCell

TableCell — атом строки: из его ячеек собирается любая колонка. Table — контейнер вокруг готовых строк: тулбар, скролл с липкой шапкой, футер, состояния Loading/Empty на уровне всей таблицы, а не одной ячейки.

Table vs Tile

Table — сама себе контейнер (фон, рамка, радиус) и её не нужно оборачивать в Tile. Если реестр — часть более крупной рабочей области с заголовком раздела, ставьте Table внутрь Tile --headless, не дублируя рамку.

Анатомия

Три вертикальные секции внутри общей рамки: Toolbar, прокручиваемое тело (шапка + строки) и Footer. Тулбар и футер — опциональны по отдельности; тело — обязательная часть всегда.

  • 1Toolbar — заголовок + счётчик записей слева, TableFilter и первичные действия справа. Опционален.
  • 2Шапка (sticky) — TableHeader-ячейки (.th), закреплена сверху при вертикальном скролле тела.
  • 3Строки — TableCell-ячейки (.tbl__row/.tc), своего оформления Table не добавляет.
  • 4Footer — Pagination: обычный ряд .pgn-row или, при выборе строк, ряд массового действия .pgn-bulk над ним. Опционален.

Варианты

Table — не набор визуальных тем, а набор независимо включаемых частей контейнера.

Настройка колонок

Кнопка-шестерёнка (settings) в тулбаре открывает Modal --w4 со списком колонок: чекбокс видимости, перетаскивание за иконку слева меняет порядок в таблице, IconButton закрепления справа — то же закрепление, что и у колонки (фон Pinned + sticky). «Выбрать все»/«Сбросить все» — массово переключают видимость. Select/Действие в списке не участвуют — служебные, не скрываются и не переставляются.

Сохранённые фильтры

Если у таблицы есть сохранённые пресеты фильтра, кнопка «Фильтр» становится Split Button (см. TableFilter): основная часть открывает модалку фильтра, шеврон — меню сохранённых пресетов с числом параметров у каждого. Без пресетов — обычная одиночная кнопка.

Тулбар

Опционален: таблица без заголовка (например, вложенная в Tile с собственным TileHeader) убирает .dtable__toolbar целиком — тело начинается сразу липкой шапкой.

Липкая шапка

Не отключаемая опция: пока у тела есть вертикальный скролл, шапка (.th) держит position: sticky; top: 0 и остаётся видимой. Если строк мало и скролла нет — шапка визуально не отличается от обычной.

Массовые действия

Появляются в Footer, когда выбрана хотя бы одна строка: ряд .pgn-bulk со счётчиком и кнопками действий встаёт НАД строкой пагинации, которая остаётся видимой. Если Footer выключен, массовые действия недоступны — включите Footer.

Горизонтальный скролл и закрепление колонок

Когда колонки не помещаются по ширине, тело скроллится горизонтально; закреплённые колонки (свойство TableCell) остаются на месте. По краям тела, где есть скрытый контент, появляется тень (.dtable--edge-l/--edge-r).

Размеры

Не применимо: собственной размерной шкалы у Table нет. Высота строки (48px) и паддинги ячеек задаёт TableCell; высота ряда пагинации — Pagination. Table лишь добавляет фиксированные отступы Toolbar (16/20px) и Footer (0/20px по бокам).

Контент

Правила наполнения контейнера.

Заголовок и счётчик

Заголовок — короткое название реестра («Заявки», «Контрагенты»). Счётчик — общее число записей без слова «записей»/«шт.», само число рядом с заголовком серым цветом.

Пустое состояние

Иллюстрация (empty-folder) + заголовок 3–5 слов + пояснение в одно предложение + опциональное действие («Очистить фильтр», «Добавить запись»). Текст объясняет причину: нет данных вообще или ничего не найдено по фильтру — формулировки разные.

Загрузка

Строки-скелетоны того же количества колонок, что и реальные данные (обычно 5–8 строк) — заголовок и счётчик тулбара на время загрузки не скрываются, счётчик можно временно спрятать, если итог неизвестен.

Переполнение

Названия колонок и значения ячеек усекаются правилами TableCell (тултип на усечении); Table не вводит собственных правил переполнения контента строк.

Поведение

Скролл, липкая шапка, переключение между обычным и массовым режимом футера, состояния Loading/Empty.

Липкая шапка при скролле

Тело — overflow: auto; шапка внутри него position: sticky; top: 0 с непрозрачным фоном (наследует --bgtable из TableCell), поэтому строки не проступают сквозь неё. Когда тело реально проскроллено вниз (scrollTop > 0), под шапкой появляется тонкая тень-разделитель — иначе липкая шапка визуально слипается со строками.

Тени горизонтального скролла

Если scrollLeft > 0 — тень слева (есть скрытый контент до текущей позиции); если scrollWidth - scrollLeft - clientWidth > 0 — тень справа. Проверка — на scroll и resize/ResizeObserver (колонки могли измениться в ширину).

Переключение в режим массового действия

Выбор строки чекбоксом (TableCell) увеличивает счётчик выбранных; при переходе счётчика от 0 к 1 Footer добавляет ряд .pgn-bulk над строкой пагинации. Снятие последнего выделения убирает ряд. Сама пагинация не пропадает и не блокируется.

Пустое состояние и загрузка

Loading и Empty подменяют содержимое тела целиком (шапка и строки не рендерятся вместо них); Toolbar и Footer при этом остаются на своих местах — заголовок, счётчик и фильтр видны и во время загрузки, и когда результат пуст.

Колонка действий

Если у таблицы есть отдельная колонка «Действие» — её кнопки (IconButton neutral S) показываются всегда, а не по hover строки: это её единственное содержимое, прятать нечего, в отличие от .tc__hidden у TableCell, где действия — надстройка над обычным контентом ячейки. Если массовое удаление доступно в панели .pgn-bulk, то же действие удаления обязательно есть и на уровне отдельной строки в колонке действий — массовое действие не может быть единственным способом что-то удалить.

Адаптивность

На узких экранах вторичные действия тулбара уходят в MenuButton (как в PageHeader); ширина колонок и необходимость горизонтального скролла остаются на стороне TableCell.

Состояния

Три состояния тела: Default (данные), Loading (загрузка), Empty (пусто). Disabled у контейнера нет — как и у TableCell, недоступной может быть отдельная строка/ячейка, не вся таблица.

Доступность

  • Разметка строк/ячеек — нативная table или role="grid", правила — на стороне TableCell.
  • Тулбар — не самостоятельный landmark; заголовок реестра — обычный заголовочный уровень (h2/h3 по контексту страницы), не h1.
  • Изменение счётчика выбранных строк — aria-live="polite" на .pgn-bulk__count, чтобы скринридер озвучивал новое число без повторного фокуса.
  • Состояние загрузки — aria-busy="true" на .dtable.
  • Пустое состояние — иллюстрация aria-hidden="true", текст читается как обычный контент (не отдельная область alert/status).
  • Горизонтальный скролл тела достижим с клавиатуры (tabindex="0" на скролл-контейнере, если внутри нет иных фокусируемых элементов раньше первой ячейки).

Типографика

Заголовок тулбара — --type-h5-strong (18/24, SB Sans Display), как заголовок Tile. Счётчик и вспомогательный текст — --type-body-s. Текст пустого состояния — заголовок --type-body-m-strong, пояснение --type-body-s. Содержимое строк и шапки — токены TableCell.

Цвета

  • Фон контейнера и тела — --bg-tile; рамка — --border-light; радиус — --radius-xl.
  • Разделители Toolbar/Footer — --border-light; тень под липкой шапкой — --border-primary.
  • Тени горизонтального скролла — производные от --text-primary (color-mix, не литерал).
  • Фон и текст строк/шапки — токены TableCell (--bgtable*, --text-*); фон ряда массового действия — токены Pagination.
  • Заголовок и счётчик пустого состояния — --text-primary/--text-secondary.
