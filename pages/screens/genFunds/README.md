# genFunds — экраны модуля «Фонды и активы»

Отдельный новый раздел продукта (не часть «Сделок»/«Клиентов») — Pro Workstation
для банкиров и инвестиционных аналитиков: фонды, активы, идеи сделок,
коммуникации. ТЗ — `uploads/brd-funds.md`.

Сюда агент-дизайнер `ai-designer` (opencode) через субагента `screen-builder`
складывает результат сборки по этому ТЗ. Конвенция файлов и правила работы —
как в `pages/screens/genOD/README.md`: на один экран два файла с одинаковым
именем (`<Имя>.html` — макет, `<Имя>.screen.md` — спецификация для
разработчика), `<Имя>` латиницей CamelCase.

## Гэпы по компонентам ДС (зафиксировано 26.08.2026)

На момент старта модуля в ДС нет: Timeline (лента истории/таймлайн),
древовидного чекбокс-фильтра (TableFilter — плоский), паттерна
дашборда/канбана, степпера/wizard-каркаса, календарной сетки. Решение
пользователя: на первых экранах эти места собираются композицией из
существующих компонентов **без** завода новых компонентов ДС. Если по ходу
сборки конкретного экрана выяснится, что композиция не работает или решение
понадобится переиспользовать в нескольких местах — это отдельный вопрос
пользователю, а не тихое решение агента.
