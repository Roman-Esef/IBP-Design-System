Pagination

Нижняя строка многостраничной таблицы: переключение страниц, выбор количества строк на странице и счётчик диапазона. Та же строка может нести панель массового действия над выбранными строками (Action panel) или информационную сводку (Pagi counters) — но сам пагинатор всегда справа. Один фиксированный размер, совпадающий с высотой строки таблицы.

Конструктор

Соберите строку колонтитула: общее число строк, размер страницы, левый слот (пусто / инфо-сводка / массовый выбор), состояние. Кликайте по номерам страниц в превью — как в реальном пагинаторе. Сузьте превью сплиттером, чтобы увидеть компактный режим.

Использование

Пагинатор встраивается в нижнюю строку таблицы и занимает её целиком. Ячейка с пагинатором не имеет отдельного состояния Selected/Focus — она не является строкой данных. Появляется, когда общее число строк превышает размер одной страницы; при единственной странице показывается статичный счётчик без интерактива (см. «Контент»).

Таблица с нижней строкой пагинатора

Поведение при скролле таблицы

Если у таблицы горизонтальный скролл — строка пагинатора в нём не участвует: она вынесена из прокручиваемой области и всегда во всю ширину контейнера. Если у таблицы вертикальный скролл — строка пагинатора накладывается поверх последних видимых ячеек (position: sticky, непрозрачный фон, тень снизу вверх).

Горизонтальный скролл — пагинатор не скроллится

Вертикальный скролл — пагинатор поверх ячеек

В контейнере со Splitter (мастер-деталь)

В таблицах с раскрывающимися подробностями (список слева + карточка объекта справа, разделены компонентом Splitter) строка пагинатора растягивается на ширину именно левой панели со списком — не всего контейнера. Перетащите сплиттер.

Анатомия

Строка состоит из левого информационного слота (опционально) и пагинатора справа: выбор размера страницы, счётчик диапазона и навигация — стрелки, номера, свёрнутый диапазон.

  • Инфо-слот (опционально)Pagi counters — сводка вроде «Сумма дохода: …»
  • Выбор размера страницынеинтерактивный текст «Показывать строк: N» + IconButton-M чеврон, открывающий DropdownList
  • Счётчик диапазона«N из M» — текущая страница из общего числа страниц
  • Стрелка «назад»disabled на первой странице
  • Номер страницыdefault / hover / current
  • Свёрнутый диапазон «…»не интерактивен — скрытые страницы между краем и текущей
  • Стрелка «вперёд»disabled на последней странице

Размеры

Один фиксированный размер: высота строки пагинатора равна высоте строки таблицы (единая сетка колонтитула), кнопки номеров и стрелок — квадрат 32 px. Отдельных размерных модификаций (M/S/XS) у компонента нет — под разную плотность таблицы меняется не пагинатор, а высота строки, к которой он подстраивается через --pgn-h.

Контент

Размер страницы — фиксированный список вариантов: 5 · 10 · 15 · 20 · 50 · Все. «Все» — отдельное состояние: выводит все строки на одной странице (при большом объёме данных предупредите пользователя, что это может быть медленно — см. «Для разработчиков»).

Открытый список выбора размера страницы

Как считаются видимые номера — свёртывание в «…»

Правило: всегда видны первая и последняя страница и 1 страница вокруг текущей (сосед слева/справа). Остальные номера сворачиваются в «…» — но если под «…» скрывалась бы только одна страница, она показывается вместо многоточия (не бывает «дыры» в одну страницу).

Поведение

Правила поведения: позиционирование, переполнение, анимация, адаптивность.

Адаптивность

Пагинатор перестраивается не по брейкпоинтам вьюпорта и не по фиксированным порогам ширины, а по фактически доступному месту: скрипт измеряет ширину строки и натуральную ширину инфо-сводки, после чего понижает уровень навигации, пока пара «сводка + пагинатор» не уложится в строку. Раскладка выбирается по правилу максимума номеров: если в одну строку рядом со сводкой помещается не худший уровень, чем в вертикали, — остаёмся в одну строку (колонтитул ниже); иначе строка складывается в вертикаль, где сводка и пагинатор получают всю ширину. Инфо-сводка никогда не обрезается и не выходит за границы своего слота, а пагинатор — за правый край строки.

Две независимые оси: data-tier на .pgn — уровень навигации; data-layout на .pgn-row — раскладка строки (row / stack). Поэтому пагинатор умеет стать компактным, оставаясь в одну строку со сводкой, — раньше compact включался только вместе с вертикалью, из-за чего стрелки успевали вылезти за границу.

Живой ресайз

Потяните за правый нижний угол рамки — пагинатор будет перестраиваться в реальном времени.

Уровни

Состояния

Номер страницы проходит Default → Hover → Current. Current не имеет hover — он уже визуально выделен и не кликабелен. Стрелки получают Disabled на границах диапазона (первая/последняя страница).

Composability — Action panel и Pagi counters

Строка колонтитула модульна: справа всегда пагинатор (или ничего, если данные умещаются на одну страницу без «Все»), слева — по обстоятельствам: ничего или информационная сводка. Когда в таблице выбрана хотя бы одна строка, панель массового действия (Action panel) появляется отдельной строкой над строкой пагинатора — сам пагинатор остаётся на месте и работоспособен, обе панели видны одновременно.

Доступность

Навигация обёрнута в <nav aria-label="Страницы">; текущая страница помечена aria-current="page" и не является кнопкой-ссылкой на себя. Стрелки на границах — aria-disabled="true", а не просто визуально приглушены. Каждый интерактивный элемент — фокусируемая кнопка со стандартным фокус-кольцом ДС (2px solid var(--primary)). Выбор размера страницы — обычный триггер DropdownList: aria-haspopup="listbox", список — role="listbox"/option. Свёрнутый диапазон «…» не интерактивен и не должен получать фокус.

Для разработчиков

Страница ДС собрана на чистых CSS-классах и vanilla JS — но всё ниже не привязано к стеку: команда, которая верстает компонент на React, может взять отсюда анатомию, точные размеры, алгоритм свёртывания номеров и цвета, не заглядывая в этот код построчно.

Точные размеры (redline)

Значения — токены ДС, измеренные через getComputedStyle на реально отрендеренном экземпляре; ссылки на переменные — в файле styles/pagination.css.

Поведение · псевдокод (framework-agnostic) 
// 1. totalPages — из общего числа строк и размера страницы («Все» = 1 страница)
totalPages = pageSize === 'all' ? 1 : Math.ceil(totalRows / pageSize)
page = clamp(page, 1, totalPages)

// 2. Свёртывание номеров в «…» — boundaryCount (края) + siblingCount (вокруг текущей),
//    по умолчанию оба = 1. Если бы «…» скрывало ровно 1 страницу — показать её вместо «…».
function pageWindow(current, total, siblingCount = 1, boundaryCount = 1) {
  totalNumbers = boundaryCount*2 + siblingCount*2 + 3
  if (total <= totalNumbers) return range(1, total)     // всё помещается — без «…»

  leftSibling  = max(current - siblingCount, 1)
  rightSibling = min(current + siblingCount, total)
  showLeftEllipsis  = leftSibling  > boundaryCount + 2
  showRightEllipsis = rightSibling < total - boundaryCount - 1
  // комбинируем: [края] + [«…» либо доп. номера] + [соседи текущей] + [«…» либо доп. номера] + [края]
  // полную сборку веток см. ds-pagination.js → pageWindow()
}

// 3. Пересчитывать pageWindow при смене page / totalRows / pageSize.
// 4. Компактный режим — по ширине контейнера строки (ResizeObserver),
//    не по брейкпоинту вьюпорта: строка может быть узкой в широком окне (виджет/сайдбар).
//    Порогов ширины нет: считаем требуемую ширину пагинатора на каждом уровне
//    (pagesize + счётчик + кнопки) и вычитаем натуральную ширину инфо-сводки:
//      avail = rowInnerWidth − infoWidth − rowGap
//      levels = [full(7) → short(5) → onlyCurrent(1) → compact(«N из M»)]
//      iRow   = первый уровень, у которого need(level) ≤ avail
//      iStack = первый уровень, у которого need(level) ≤ rowInnerWidth
//      iRow не хуже iStack → layout = 'row', иначе layout = 'stack'
//      (в вертикали сводка сверху во всю ширину, пагинатор снизу; крайний уровень — xs)
//      подъём к более полному набору требует запаса 24px — гистерезис против дребезга,
//      когда появление/исчезновение скроллбара меняет ширину на ~15px.

// 5. Массовый выбор строк таблицы добавляет панель НАД строкой пагинатора,
//    не заменяя её — обе видны и активны одновременно:
renderFooter({
  bulkPanel: selectedCount > 0 ? { count: selectedCount, actions } : null,
  pagerRow: { info, pager },
})

Это не готовый сниппет для вставки — алгоритм для реализации поверх вашего стека (в этом ДС — vanilla JS, см. pagination.page.js, функции pageWindow и buildPager, если нужен рабочий референс).

Бэклог

Кейсы, которых недостаёт документации, — на существующих токенах и компонентах.

  • Переход «В начало / В конец» — быстрые кнопки-стрелки к первой/последней странице.
  • Ввод номера страницы вручную — поле для прямого перехода при большом количестве страниц.
  • Выпадающий список страниц при клике на троеточие «…» в списке номеров страниц.
